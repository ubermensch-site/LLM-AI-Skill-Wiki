# SkillCorpus

**What it is:** SkillCorpus is open-source infrastructure for turning scattered `SKILL.md` files into curated, retrieval-ready agent-skill corpora — with retrieval + evaluation tooling included.

**Why it’s useful:**
- Helps teams *organize* many skills into a searchable corpus instead of a loose folder tree
- Includes tooling to support retrieval (skill routing / semantic search) and evaluation of skill sets
- Designed for the emerging `SKILL.md` ecosystem across agent harnesses

**Why it’s trusted:**
- Maintained by the EverMind-AI org and quickly earned significant community traction
- Clear focus on infrastructure + evaluation (not a thin “prompt dump”)

**Source:** https://github.com/EverMind-AI/SkillCorpus
