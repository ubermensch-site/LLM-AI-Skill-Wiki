# bitbucket-cli (bkt)

**What it is:** `bkt` is a standalone Bitbucket CLI (Cloud + Data Center) designed with **automation-first, JSON/YAML-friendly output** and `gh`-like ergonomics. It also ships a **first-class Agent Skills / SKILL.md-compatible skill bundle** so coding agents (Claude Code, Codex, Cursor, Copilot, Gemini CLI, etc.) can work with Bitbucket workflows more reliably.

## Why it’s worth including

- **Substantive, real tooling (not promptware):** a full Go CLI with structured outputs and documented workflows.
- **Explicit agent-skill support:** ships canonical skill files and documents installation via `npx skills` / `skild` / manual copy.
- **Security posture:** CI + secret scanning + OpenSSF Scorecard badge in the upstream repo.
