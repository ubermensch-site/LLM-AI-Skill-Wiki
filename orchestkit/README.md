# OrchestKit

OrchestKit is a production-oriented agent plugin with 110 skills, 36 agents, and 162 hooks for software review, testing, security, memory, browser verification, and shipping workflows. It is primarily a Claude Code plugin and also documents portable installs for Cursor, Codex, pi, Devin, and other Agent Skills-compatible hosts.

## Why it qualifies

- MIT-licensed and actively released with a substantial source tree, tests, CI, changelog, and security policy.
- Documents its hook scope, local event storage, opt-outs, network behavior, and cross-harness limitations instead of hiding them.
- Provides a real installable plugin and generated skill catalog rather than a prompt-only README.
