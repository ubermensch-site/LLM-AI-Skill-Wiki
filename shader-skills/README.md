# Shader Skills

Shader Skills is a focused Agent Skills collection for writing, debugging, optimizing, and bundling procedural GLSL for Shadertoy and WebGL2. It includes 197 documented GLSL functions across 21 modules, 27 interactive shader studies, a dependency bundler, and compile/property checks.

## What it includes

- `shader-art-coding`: a routing and implementation workflow for SDFs, noise, ray marching, lighting, color, water, atmosphere, and post-processing.
- A dependency-aware bundler that emits self-contained shaders from named library functions.
- A checker and WebGL2/GLSL ES 3.00 verification workflow covering syntax, portability, numerical properties, and rendered studies.
- Reusable templates, reference guides, offline gallery examples, and WebGPU worlds for learning and experimentation.
- Installation guidance for Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot, and other compatible agents.

## Install

```bash
npx skills add gokayfem/shader-skills
```

The repository also provides Claude Code plugin installation and manual paths for other agents.

## Why it qualifies

This is a substantive, MIT-licensed skill collection with a clear scope, extensive technical documentation, automated checks, GPU property tests, compile-checked examples, and an active release history. It had 483 stars and 37 forks when reviewed. The repository credits the upstream shader research and documents its implementation limits rather than presenting unverified prompt-only guidance.
