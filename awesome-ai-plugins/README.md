# Awesome AI Plugins

A cross-platform catalog of plugins, Agent Skills, MCP servers, apps, and related tools for Claude Code, Codex, ChatGPT, Gemini CLI, Cursor, OpenCode, and other AI assistants.

## Why it qualifies

- **Curated discovery:** the upstream project maintains a structured registry rather than a single-purpose prompt or clone.
- **Broad Agent Skills coverage:** listings include projects targeting the Agent Skills and MCP standards, with supported clients and installation details called out per entry.
- **Substantive maintenance:** the repository includes a large machine-readable `plugins.json` catalog, validation tests, contribution guidance, and an Apache-2.0 license.
- **Useful scope:** it complements skill-only indexes by covering the surrounding plugin and tool ecosystem across multiple agent harnesses.
