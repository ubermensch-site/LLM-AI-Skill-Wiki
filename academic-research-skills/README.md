# Academic Research Skills for Claude Code

A comprehensive Claude Code skill suite for the academic-research pipeline: planning, literature review, evidence extraction, writing, review, revision, reproducibility, and publication. It is a substantial workflow system rather than a single prompt, with dedicated skills, agents, commands, hooks, examples, evaluations, and setup documentation.

## Why it is trusted

- Versioned releases, a DOI, citation metadata, governance documentation, and a detailed changelog.
- Clear research and publication workflow boundaries, including human review and anti-fabrication guidance.
- Extensive documentation and a large test/evaluation surface across the repository.
- CC BY-NC 4.0 licensing is stated explicitly; check the source license before commercial use.

## Highlights

- Research planning and Socratic paper-structure guidance.
- Deep research, academic-paper drafting, reviewer response, and revision workflows.
- Citation, evidence, audit, and publication-readiness checks.
- Claude Code plugin packaging with commands, agents, hooks, examples, and evals.

## Install

Install it as a Claude Code plugin:

```text
/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills
```

The repository also documents symlink and Claude.ai/Claude Desktop installation methods.
