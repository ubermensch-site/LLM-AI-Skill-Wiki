# Nature Paper Skills

A focused collection of 27 Codex and Claude Code skills for evidence-grounded life-science, computational-biology, and methods manuscripts, from research framing through figures, revision, submission, and reviewer rebuttal.

## What it includes

- Paper framing, claim-to-evidence planning, and section-specific workflows for abstracts, introductions, results, discussions, and methods.
- Figure planning and optional production/QA workflows, with figure-led Results alignment.
- Scientific writing, citation support checks, anti-defensive editing, statistics-aware revisions, and venue-aware structure.
- Submission audits, preflight checks, data/availability review, and evidence-linked reviewer responses.
- Reusable profiles: a 19-skill writing/review set, a 21-skill set with figure tools, or the complete 27-skill collection.
- Explicit evidence-preservation rules that retain measurements, uncertainty, negative results, and scope conditions instead of inventing support.

## Installation

For the full profile with Codex or Claude Code:

```bash
curl -fsSL https://raw.githubusercontent.com/Boom5426/Nature-Paper-Skills/main/install.sh | bash -s -- --agent codex --set all
```

Use `--agent claude` for Claude Code or choose the smaller profiles documented upstream. The installer records provenance, supports dry runs and restore, and includes compatibility and behavior checks.

## Why it is trusted

The repository is a substantive, MIT-licensed research workflow with documented examples, installer tests, evaluation cases, provenance tracking, and strong boundaries against fabricating evidence. Its guidance is explicitly presented as descriptive workflow support rather than journal acceptance or formatting guarantees.
