# OK Skills

A curated collection of 32 reusable AI coding-agent skills and `CLAUDE.md` / `AGENTS.md` playbooks for Codex, Claude Code, Cursor, OpenClaw, Autohand Code, Trae, and other `SKILL.md`-compatible tools.

## What it includes

- Planning and research workflows such as `planning-with-files`, `find-docs`, and `find-skills`
- Browser automation, debugging, and QA skills
- Engineering practices including TDD, diagnostics, domain modeling, and architecture improvement
- Frontend, design, document, PDF, Office, and spreadsheet authoring skills
- A portable repository layout with one top-level directory per skill

## Why it is trustworthy

The repository is a maintained, documented collection rather than a prompt dump: it provides multilingual documentation, explicit installation guidance, reusable skill directories, and upstream references for vendored skills. It is also listed by the Awesome Codex CLI community.

## Install

```bash
mkdir -p ~/.agents/skills
cd ~/.agents/skills
git clone https://github.com/mxyhi/ok-skills.git ok-skills
```

See the upstream README for the complete skill index, prerequisites, and provider-specific installation instructions.
