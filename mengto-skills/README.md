# Meng To Skills

A large, portable collection of agent skills for designers and builders using Codex, Claude, Cursor, Aura Build, Lovable, and other coding agents. The repository turns design references, UI systems, playable games, 3D scenes, media workflows, and engineering routines into versioned `SKILL.md` procedures.

## Why it qualifies

- Authored and actively maintained by Meng To, a recognized design-tool creator.
- Provides a substantial, browsable skill library with clear folder contracts, portability guidance, demos, references, and an MIT license.
- The repository is updated frequently with new workflows and visual implementation skills rather than being a static prompt list.
- Each skill documents triggers, defaults, implementation steps, pitfalls, and acceptance checks where appropriate.

## Key features

- Web design, UI, 3D rendering, illustration, game development, game combat, video editing, media, Codex workflows, and team workflows.
- Portable skill folders with optional references, articles, scripts, assets, demos, and testable output.
- Guidance for Codex, Claude Code, Cursor, and other agents that can load Markdown skills.
- Reusable prompt assets, screenshot/reference study, visual QA, and implementation recipes.

## Install

Clone the collection and load the narrowest matching skill before acting:

```bash
git clone https://github.com/MengTo/Skills.git
```

Browse the `agent-skills/` tree for the specific workflow you need; the upstream README documents the folder contract and agent-specific usage.
