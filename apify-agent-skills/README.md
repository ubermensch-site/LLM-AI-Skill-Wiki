# Apify Agent Skills

Production-grade web scraping, Actor development, and Apify integration skills for AI coding agents. The collection supports Claude Code, Cursor, Windsurf, Codex, Gemini CLI, and other agents that read `SKILL.md` files.

## What it includes

- **apify-ultimate-scraper** — selects and runs Apify Actors for social, search, maps, commerce, reviews, and other web-data workflows.
- **apify-actor-development** — creates, debugs, and deploys JavaScript, TypeScript, and Python Actors, including input/output schemas.
- **apify-actorization** — wraps existing scripts, libraries, or CLI tools as runnable Actors.
- **apify-integration-development** — builds Apify integrations for workflow tools, agent harnesses, AI frameworks, and direct clients.
- **apify-fix-git-connection** — diagnoses and repairs Actor deployments connected to GitHub.

The repository also includes an `apify-actor-commands` command pack and cross-agent indexes under `agents/AGENTS.md`.

## Install

```bash
npx skills add https://github.com/apify/agent-skills --skill apify-ultimate-scraper
```

For Claude Code, the repository can also be added as a plugin marketplace:

```text
/plugin marketplace add https://github.com/apify/agent-skills
```
