# Claude Code Frontend Design Toolkit

A curated reference for making AI-generated frontends more polished, covering design skills, plugins, MCP servers, framework workflows, browser testing, visual feedback, and deployment.

## Why it qualifies

- **1,300+ GitHub stars and 150+ forks** with active maintenance.
- Organizes 64 entries into 11 practical sections rather than presenting an unstructured link dump.
- Gives installation guidance for official and third-party plugins and the `skills` CLI.
- Focuses on repeatable frontend quality workflows: design systems, animation, UI/UX research, design-to-code, testing, and visual review.

## Capabilities

- Points agents to design skills and resources for reducing generic “AI slop.”
- Covers site-wide theming, design tokens, motion, component registries, and framework-specific skills.
- Connects frontend implementation with browser automation, visual feedback, documentation, and deployment.
- Includes recommended stacks and quick-reference installation commands.

## Install / use

This is a curated reference rather than one executable package. Follow the per-entry instructions in the source README; many skills can be installed with:

```bash
npx skills add owner/repository
```
