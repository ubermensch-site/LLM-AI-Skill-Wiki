# Taste Skill

A collection of 5 skills that improve how AI tools write frontend code — pushing toward modern, premium designs with proper animation, spacing, and visual quality instead of generic, boring interfaces.

## The 5 Skills

1. **taste-skill** — main design skill: layout, typography, color, spacing, motion, overall visual quality. Has 3 tunable settings (1–10): `DESIGN_VARIANCE`, `MOTION_INTENSITY`, `VISUAL_DENSITY`.
2. **redesign-skill** — for upgrading existing projects: audit what exists, fix the biggest design problems first.
3. **soft-skill** — makes things look/feel expensive: premium fonts, big whitespace, layered depth cards, spring animations, floating nav. Bans generic AI-slop defaults.
4. **output-skill** — stops the AI from being lazy: no placeholder comments, no skipped code blocks, no half-finished output.
5. **minimalist-skill** — clean, editorial interfaces inspired by Notion/Linear: warm monochrome, serif/sans contrast, flat bento grids, hairline borders, no gradients/heavy shadows.

## How to use

Copy the relevant `SKILL.md` into your project and tell your AI agent to read and follow it (e.g. `@SKILL.md` in Cursor).
