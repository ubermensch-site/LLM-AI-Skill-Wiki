# ZenStory Drama Skills

A production-oriented skill suite for AI short dramas and motion comics. It covers the path from an idea or source novel through episode scripts, visual assets, storyboards, image/video prompts, confirmed production, editing, and review for Claude Code, Codex, and other Agent Skills-compatible environments.

## Why it qualifies

- Nearly 3,900 GitHub stars and 600+ forks with active releases and CI.
- Maintained by ZenStory AI, an identifiable AI story-production team.
- Includes real examples, validation scripts, documented production boundaries, and an MIT license.

## Key capabilities

- Novel analysis, story development, episode writing, and asset decisions.
- Continuity locks, frozen keyframes, shot plans, and model-specific video prompts.
- Confirmation gates before paid image, video, voice, or music production.
- Editing, subtitles, audio/QC checks, and review workflows.

## Install

```bash
npx skills add zenstory-ai/drama-skills -y -g
```
