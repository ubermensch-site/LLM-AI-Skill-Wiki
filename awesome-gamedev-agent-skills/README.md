# awesome-gamedev-agent-skills

A high-quality, cross-engine collection of **74 game-development Agent Skills** (in `SKILL.md` format) plus a **router** that automatically loads the right skills based on your engine and request.

## Why this is worth including

- **Substantive and maintained**: a large, organized catalog (74 skills) with clear documentation and an explicit validation workflow.
- **Practical structure**: skills are grouped by engine (Godot/Unity/Unreal/etc.), discipline (AI, save systems, UI/UX, performance), genre (RPG, roguelike, platformer), and workflow (game jam, Steam/itch publishing).
- **Trust signals**: Apache-2.0 licensed, actively updated, and designed to be portable across major coding-agent harnesses.
