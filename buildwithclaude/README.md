# Build with Claude

[Build with Claude](https://github.com/davepoon/buildwithclaude) is an open-source Claude Code marketplace and discovery platform. Its repository ships curated agents, commands, hooks, skills, and plugins, while its web catalog helps users browse community plugins and MCP servers with install commands and usage documentation.

## Why it is trusted

- MIT-licensed and maintained as a public marketplace repository with contribution and validation guidance.
- Includes a substantial first-party collection: 117 agents, 175 commands, 28 hooks, 26 skills, and 51 plugins as documented by the project.
- Provides real Claude Code marketplace installation paths, categories, examples, and a browsable web index.
- Useful as a discovery layer, while each third-party plugin should still be reviewed before installation.

## Installation

```bash
/plugin marketplace add davepoon/buildwithclaude
/plugin search @buildwithclaude
/plugin install <plugin-name>@buildwithclaude
```

Browse the [source repository](https://github.com/davepoon/buildwithclaude) and [Build with Claude web catalog](https://www.buildwithclaude.com) for the current plugin, skill, agent, and MCP listings.
