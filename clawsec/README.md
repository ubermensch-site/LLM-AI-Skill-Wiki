# ClawSec

ClawSec is a security-focused collection of Agent Skills and signed advisory intelligence for AI agent runtimes. It covers OpenClaw, NanoClaw, Hermes, and Picoclaw with guarded skill installation, integrity and drift checks, posture audits, and platform-specific security workflows.

## Why it qualifies

- Backed by Prompt Security, from SentinelOne.
- Ships signed advisory material, CI workflows, validation tooling, and detailed security documentation.
- Provides concrete runtime-oriented protections rather than a prompt-only collection.

## Source

- Repository: [prompt-security/clawsec](https://github.com/prompt-security/clawsec)
- Install instructions and the current skill catalog are maintained in the source repository.

Use only for authorized defensive security work and review the permissions and hooks before enabling them.
