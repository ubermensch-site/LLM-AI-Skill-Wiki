# 花叔Design (Huashu-Design)

An HTML-based design skill for high-fidelity prototypes, interactive demos, slide decks, and animation — HTML is the *tool*, not the medium, so the agent embodies the right specialist per task (UX designer, animator, slide designer, prototyper) instead of producing generic web-app-looking output.

## Core Principles

- **Fact verification before assumptions**: for any concrete product/tech/version claim, `WebSearch` first — never assert from training data alone.
- **Design from existing context**: pull from a real design system / brand assets before designing from scratch; if none exists and the brief is vague, falls back into a "design direction advisor" mode offering 3 differentiated directions from 20 design philosophies (Pentagram, Field.io, Kenya Hara, Sagmeister, etc).
- **Core asset protocol**: when a real brand/product is involved, always source its actual logo, product photos, and UI screenshots — never fake them with CSS silhouettes.
- Ships with a Junior-Designer-style workflow (hypothesis + reasoning + placeholder before iterating), an anti-AI-slop checklist, Playwright verification, and HTML-animation-to-MP4/GIF export tooling.

## Use Cases

Interactive prototypes, design-variant exploration, 1920×1080 slide decks, motion-design demos, infographics/visualizations.
