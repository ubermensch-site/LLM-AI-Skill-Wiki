# OpenViking

OpenViking is an open-source context database from Volcano Engine for AI agents. It unifies knowledge, long-term memory, and skills in an inspectable `viking://` filesystem, with directory summaries, scoped retrieval, a CLI/server, SDKs, and integrations for Claude Code, Codex, Cursor, OpenCode, and other agent environments.

## Why it is trustworthy

- Maintained by the official Volcano Engine organization.
- Substantive AGPLv3 project with public documentation, SDKs, deployment guidance, security material, and reproducible benchmark reports.
- Treats skills and memories as inspectable, editable resources instead of opaque embeddings.
