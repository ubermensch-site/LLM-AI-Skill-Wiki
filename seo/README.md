# SEO Skill

SEO Skill gives AI agents a CLI and MCP server for evidence-based SEO work. It reads Search Console, Google Analytics, Bing Webmaster Tools, crawl results, keyword data, SERPs, competitors, and backlinks while keeping source dates, limits, and provider estimates explicit.

## Why it qualifies

- Substantive TypeScript implementation with eight documented commands, local and hosted MCP modes, tests, CI, and an npm package.
- Apache-2.0 licensed with published security, privacy, and contributor documentation.
- The workflow is designed around inspecting facts and asking before changing a page, not making unsupported ranking promises.
