# SkillMD

SkillMD is an open toolchain and registry for the `SKILL.md` format. It provides a CLI, MCP server, GitHub Action, parser/linter, quality scoring, security scanning, SARIF output, and safe installation across dozens of agent clients.

## Why it qualifies

- MIT-licensed implementation with separate core and CLI packages, CI, tests, and a published npm toolchain.
- Lints and scans skills for network calls, script execution, secret access, and unsafe installation behavior.
- Supports discovery and installation as well as authoring and GitHub Code Scanning integration.
