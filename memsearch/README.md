# MemSearch

MemSearch is a cross-platform semantic-memory system for AI coding agents. Its Claude Code, Codex, DeepSeek Harness, OpenClaw, and OpenCode plugins capture conversations, store human-readable Markdown memories, provide hybrid search and progressive recall, and can distill repeated workflows into reusable Agent Skills.

## Why it is trustworthy

- Maintained by Zilliz, the company behind Milvus, with a substantial open-source implementation and public documentation.
- Ships a Python package, CLI, tests, documentation, and platform-specific integrations rather than a thin prompt dump.
- Keeps Markdown as the source of truth, makes indexing rebuildable, and leaves skill installation and optional background maintenance under user control.
