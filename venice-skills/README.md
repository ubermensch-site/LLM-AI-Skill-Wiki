# Venice Skills

The official Venice AI API skill collection. It contains endpoint-focused reference skills for chat, responses, embeddings, image, audio, video, models, authentication, billing, x402, crypto RPC, errors, and more, plus workflow skills for creating media and product assets.

## Why it is trustworthy

This repository is maintained by Venice AI as the canonical source for skills derived from its public OpenAPI specification and documentation. It uses tagged releases, nightly API-drift checks, CI integrity scanning, CODEOWNERS review for security-sensitive skills, and explicit warnings around wallet keys and payments. It is MIT-licensed.

## Install

For Claude Code:

```text
/plugin marketplace add veniceai/skills
/plugin install venice@venice
```

The source README also documents pinned-release installs and copying or symlinking the `skills/` directory for Codex, Cursor, OpenCode, Cline, and other runtimes.
