# SkillOpt

SkillOpt is Microsoft’s open-source “skill optimizer” for LLM agents: it learns and refines reusable natural-language skills by iterating on trajectories, applying validation-gated edits, and exporting deployable `best_skill.md` artifacts.

It’s especially relevant for teams building **agent skills libraries** who want a more systematic way to improve prompts/skills over time (rather than ad-hoc edits), with experimentation, evaluation, and safety/quality checks.

## What it helps with

- Training / improving reusable skills for a frozen agent (prompt-only skill optimization)
- Trajectory-driven edits (learn from successful/failed runs)
- Validation-gated updates to prevent regressions
- Exporting “best skill” artifacts for deployment
