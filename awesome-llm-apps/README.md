# Awesome LLM Apps

100+ open-source AI agents, agent skills, and RAG apps — hand-built, tested end-to-end, Apache-2.0. Featured as the **#1 repository of the day on Trendshift**.

## What it does

- Dedicated `agent_skills/` directory (Project Graveyard, Scope Creep Detector, Commit Archaeologist, Dependency Doctor, Self-Improving Agent Skills, and more) — every skill ships real code and passes a security + eval CI gate
- Starter AI agents (single-file, API-key-only), advanced multi-agent teams, always-on agents, voice AI agents, generative-UI agents, and RAG tutorials
- MCP AI Agents section (GitHub MCP agent, Notion MCP agent, multi-MCP router, etc.)
- New templates ship weekly via the Unwind AI newsletter
