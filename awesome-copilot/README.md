# awesome-copilot

A community “awesome list” of **GitHub Copilot** resources — including agent instructions, reusable agent/skill configs, and examples for getting more out of Copilot in real projects.

## Why it’s worth including

- **Official GitHub-maintained** repository (not a random prompt dump)
- Very large, active community collection of **instructions / agents / skills / configurations**
- Useful cross-agent reference even if you’re not using Copilot exclusively (many patterns translate to other harnesses)
