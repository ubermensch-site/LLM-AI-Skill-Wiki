# oh-my-design

oh-my-design combines a sourced `DESIGN.md` archive for 500+ real products with frontend skills aimed at high-fidelity, culturally aware interfaces. It gives coding agents reusable design-system references and CJK-first guidance for typography, wrapping, copy, interface feel, restraint, and slop auditing.

## Why it qualifies

- More than 500 GitHub stars with active maintenance and a published CLI.
- Substantive archive: design values are graded by how well they are sourced, with unconfirmed values left blank.
- MIT-licensed, documented, and usable across Claude Code, Codex, OpenCode, and Cursor.
- Focuses on reproducible design inputs rather than a thin prompt-only package.

## Key features

- Browse or fetch product-specific `DESIGN.md` references for companies such as Toss, Stripe, LINE, pixiv, and Linear.
- CJK-first frontend skills for Korean, Japanese, and Chinese typography and copy.
- Guidance for interface feel, restraint, visual direction, and AI-slop audits.
- CLI commands for installation, updates, and diagnostics.

## Install

```bash
npx oh-my-design-cli@latest
```

The installer supports project or global installs and can target Claude Code, Codex, OpenCode, or Cursor.
