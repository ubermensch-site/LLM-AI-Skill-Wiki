# Awesome AI Agent Skills

A curated, installable collection of 103 complete `SKILL.md` workflows for Claude Code, OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot, Windsurf, and other agents supporting the open Agent Skills standard.

## What it includes

The collection covers agent engineering and security, context engineering, coding, data, DevOps, documents, research, business workflows, and more. Unlike a link-only directory, each entry is a self-contained workflow with activation guidance, procedures, validation steps, and optional scripts or references.

Notable areas include agent evaluation, observability, human-in-the-loop design, MCP server building, multi-agent orchestration, prompt-injection defense, skill supply-chain auditing, document processing, and research workflows.

## Why it qualifies

- **MIT licensed** and openly documented.
- **Cross-agent compatible**, with installation guidance for major coding-agent tools.
- **Validated in CI** with checks for skill structure, metadata, links, duplicates, catalog synchronization, and Python syntax.
- **Substantive catalog**: 103 ready-to-use workflows, starter packs, an offline production-agent safety demo, and contribution guidance.
- **Active community project** with meaningful GitHub traction and recent maintenance.
