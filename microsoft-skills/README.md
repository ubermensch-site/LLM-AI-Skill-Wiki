# microsoft-skills

An official Microsoft collection of Agent Skills, custom agents, `AGENTS.md` templates, plugins, and MCP configurations for Azure SDKs and Microsoft Foundry development.

## Why it’s useful

- Broad, practical coverage across Azure services, Foundry, Copilot SDK, MCP, frontend, and multiple SDK languages.
- The repository documents 175 skills with installable bundles, agents, prompts, and plugin packages.
- Includes acceptance criteria, test scenarios, and a Copilot SDK-based harness for evaluating skill quality.

## What’s included (high level)

- Core skills for cloud architecture, MCP server building, Copilot SDK, frontend review, and skill creation
- Foundry and Azure SDK skills for Python, .NET, TypeScript, Java, and Rust
- Deep-wiki and Azure plugins, custom agent definitions, `AGENTS.md`, prompts, and MCP server configurations
- Installation via `npx skills add microsoft/skills` or the Copilot plugin marketplace

## Trust signals

- Official repository maintained by Microsoft
- MIT-licensed and actively developed with CI, evaluation workflows, and extensive documentation
- Publicly listed test coverage includes more than 1,000 skill scenarios
