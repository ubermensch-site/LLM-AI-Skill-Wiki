# daymade/claude-code-skills

A large, actively maintained “skills marketplace” for **Claude Code**, centered around a hardened **skill-creator** meta-skill plus bundled suites for documents, ops, and power-user workflows.

## Why it’s worth including

- **Strong community traction** (~1.4k stars) and active maintenance.
- A clear focus on **production-ready workflows** (validation, security gating, packaging, and practical failure modes), not just prompt dumps.
- Includes an expanded, battle-tested fork of Anthropic’s official `skill-creator` with real-world guardrails.

## What it enables (high level)

- Create/validate/package new skills via the **skill-creator** meta-skill.
- Install suites for common workflows (docs conversion, presentations, GitHub ops, QA, etc.).
- Provides detailed methodology docs and references for repeatable skill development.
