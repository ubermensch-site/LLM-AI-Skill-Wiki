# Vercel Agent Skills

Vercel Labs' official collection of Agent Skills for AI coding agents. It packages Vercel Engineering guidance and practical workflows for React, Next.js, React Native, web design, writing, deployments, and Vercel cost and performance optimization.

## Why it is trustworthy

- Published by Vercel Labs, the team behind the Vercel platform.
- Skills follow the open Agent Skills format and include documented triggers, coverage areas, and installation steps.
- The collection is backed by concrete engineering guidance, helper scripts, discovery indexes, and an MIT license.

## Source

- Repository: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
- Install with `npx skills add vercel-labs/agent-skills`.
