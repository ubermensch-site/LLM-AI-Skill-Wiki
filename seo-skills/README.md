# SEO Skills

A substantial collection of 30 open-source `SKILL.md` workflows for Claude Code, Cursor, Codex, and other Agent Skills-compatible tools. It covers technical and on-page SEO, live SERP research, GEO/AI-search visibility, first-hand proof content, internal linking, migrations, outreach, and conversion copywriting.

## Why it qualifies

- Follows the portable Agent Skills `SKILL.md` format and supports multiple agent harnesses.
- Provides concrete, output-oriented workflows rather than a thin prompt list, with documented install paths and end-to-end compositions.
- MIT-licensed and actively maintained by Ilias Ism; the source repository had 1,250+ stars and 100+ forks when reviewed.
