# rstack

rstack is an agent development stack with seven skills and an `AGENTS.md` workflow for taking changes from an isolated worktree through evidence-backed testing and reviewed pull requests. It supports Claude Code, Cursor, Codex, and other agents that load `SKILL.md` folders.

The collection includes new-feature isolation, code-structure guidance, evidence-driven testing, before-and-after visual comparisons, bounded Greptile review loops, and AI-writing cleanup.

## Why it is trustworthy

- Provides concrete skills, scripts, tests, workflow rules, and installation guidance rather than prompt-only advice.
- Documents safety boundaries such as one worktree per task, no commits to `main`, bounded review iterations, and limitations of test coverage.
- Has strong community traction and clearly identifies vendored upstream skills and their licenses.
