# Databricks Agent Skills

Databricks' official skills and agent plugins for building applications, jobs, data pipelines, Lakebase and Model Serving workflows, Declarative Automation Bundles, and MLflow operations with Claude Code, Cursor, Codex, GitHub Copilot, and other agents.

## Why it qualifies

- Published and maintained by the official Databricks organization.
- Provides a large product-specific catalog with stable versus experimental skill boundaries.
- Includes CLI and plugin-marketplace installation, generated manifests, CI validation, code-owner review, and security guidance.

## Key capabilities

- Databricks CLI, authentication, data discovery, apps, jobs, pipelines, DABs, and SQL.
- Lakebase, Model Serving, Vector Search, AI Functions, MLflow, Unity Catalog, and more.
- Cross-agent distribution through the Databricks CLI and provider plugin bundles.

## Install

```bash
databricks aitools install
```
