# hol-guard

**hol-guard** is an “antivirus” / runtime guardrail layer for AI agents. It focuses on blocking risky tool usage, preventing secrets exposure, and mitigating prompt-injection and supply-chain threats while agents run.

## What it does

- Policy-based gating of tools/actions at runtime
- Secrets detection / secret access controls
- Prompt-injection and malicious plugin/MCP/skill risk checks
- Audit/logging-oriented security posture for agent execution

## Why it’s trusted

- Security-focused project with clear scope (runtime protection for agents)
- Active maintenance and real community traction
