# Obsidian Agent Skills

Official Agent Skills for Obsidian, following the [Agent Skills specification](https://agentskills.io/specification) so the collection works across compatible agents. It covers Obsidian Flavored Markdown, Bases, JSON Canvas, the Obsidian CLI, Headless, Defuddle, and Knap, with documented installation paths for Claude Code, Codex, Cursor, OpenCode, and `npx skills`.

## Why it is trustworthy

- Maintained by the official Obsidian organization.
- Provides source-backed, product-specific skills rather than a generic prompt collection.
- Documents installation, release maintenance, and the individual skill catalog.
