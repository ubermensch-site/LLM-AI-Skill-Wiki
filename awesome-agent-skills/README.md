# Awesome Agent Skills (by VoltAgent)

"A collection of official Agent Skills from leading development teams and the community. Hand-picked, not AI-slop generated." 1,497+ skills and growing.

## What it does

Catalogs **official skills published directly by real engineering teams**, including Anthropic, Vercel, Cloudflare, Stripe, Supabase, HashiCorp (Terraform), Sanity, Firecrawl, Neon, ClickHouse, Remotion, Replicate, Google Gemini, Google Labs (Stitch), Hugging Face, Microsoft, Figma, Notion, MongoDB, Apollo GraphQL, Auth0, Datadog Labs, Firebase, Flutter, Redis, NVIDIA, Google Cloud, and more — organized by contributing company.

Compatible with Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, and Windsurf, with a path-mapping table per tool.

Includes an explicit **Security Notice**: skills are curated but not security-audited, and the list documents install paths per host plus recommended scanning tools (Snyk Skill Security Scanner, Agent Trust Hub) before use.

## Why it's trusted

Maintained by **VoltAgent**, a real AI agent framework company, with an explicit policy against "skills you created 3 hours ago" — favoring community-adopted skills proven in real-world use and published by actual dev teams.
