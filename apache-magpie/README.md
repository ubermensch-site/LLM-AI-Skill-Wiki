# Apache Magpie

Apache Magpie is the Apache Software Foundation's curated set of agent skills for open-source project maintenance. It covers issue and pull-request triage, code review, contributor mentoring, release management, repository health, and security-report workflows for Claude Code, Codex, Copilot, and other agents.

## Why it is trustworthy

- Official Apache project under the Apache-2.0 license.
- Explicitly designed around human approval: agents draft work rather than posting or publishing in a person's name.
- Includes sandboxing, credential stripping, command guards, documentation, and multiple skill families instead of a prompt-only collection.
