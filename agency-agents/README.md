# The Agency: AI Specialists

A large collection of meticulously crafted AI agent personalities — 142 specialized agents across 12 divisions. Each agent has a distinct personality/voice, a clear mission, concrete deliverables with code examples, and measurable success metrics (not generic "act as a developer" prompts).

## Divisions

- **Engineering** (20 agents): Frontend Developer, Backend Architect, Mobile App Builder, AI Engineer, DevOps Automator, Security Engineer, Software Architect, SRE, Database Optimizer, etc.
- **Design** (8): UI Designer, UX Researcher, Brand Guardian, Whimsy Injector, Image Prompt Engineer, etc.
- **Paid Media** (7): PPC Strategist, Search Query Analyst, Tracking Specialist, Programmatic Buyer, etc.
- **Sales** (8): Outbound Strategist, Discovery Coach, Deal Strategist, Sales Engineer, Pipeline Analyst, etc.
- **Marketing** (18): Growth Hacker, Content Creator, SEO Specialist, platform specialists (TikTok, Xiaohongshu, WeChat, Bilibili, etc.)
- **Product** (4), **Project Management** (6), **Testing** (8), **Support** (6), **Spatial Computing** (6), **Specialized** (16, including MCP Builder, Blockchain Security Auditor, Compliance Auditor), **Game Development** (cross-engine + Unity/Unreal/Godot/Roblox specialists)

## Install

```bash
# Claude Code
cp -r agency-agents/* ~/.claude/agents/

# Multi-tool (Cursor, Aider, Windsurf, Copilot, Gemini CLI, OpenCode, etc.)
./scripts/convert.sh && ./scripts/install.sh
```
