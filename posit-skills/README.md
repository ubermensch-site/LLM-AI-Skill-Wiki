# Posit Agent Skills

The official [Posit](https://posit.co/) collection of open-standard Agent Skills for Posit Assistant, Claude Code, Codex, Cursor, Cline, and other compatible agent harnesses.

## What it includes

- **Posit developer workflows**: adversarial code review, architecture documentation, task tracking, and test review.
- **GitHub workflows**: create pull requests, address review threads, and resolve threads.
- **Open-source maintenance**: release checklists and release posts for R and Python packages.
- **R package development**: tidyverse style, testthat, cli, CRAN checks, lifecycle, devtools, async computing with mirai, and accessible alt text.
- **Quarto, Shiny, and Posit Connect**: authoring, branding, theming, deployment, and publishing workflows.
- **ggsql**: guidance for writing grammar-of-graphics SQL visualization queries.

## Installation

Install all skills with the cross-agent Skills CLI:

```bash
npx skills add posit-dev/skills --all
```

To browse first:

```bash
npx skills add posit-dev/skills --list
```

The repository also documents Claude Code marketplace and plugin installation, Posit Assistant installation, and manual copying for offline use.

## Why it is trusted

- Maintained by Posit, the organization behind RStudio, Shiny, Quarto, and Posit Connect.
- Uses the open Agent Skills standard and documents compatibility across multiple agent runtimes.
- MIT licensed with a substantial, organized catalog, CI/contribution guidance, and product documentation links.
