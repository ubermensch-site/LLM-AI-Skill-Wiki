# No AI Slop

Removes 20+ patterns of "AI slop" from writing without flattening personal voice.

## Patterns it catches

1. Binary contrasts ("It's not X. It's Y.") 2. Throat-clearing openers ("Here's the thing") 3. Faux-insight setups ("What nobody tells you") 4. Colon reveals ("The best part: it learns.") 5. Dramatic fragments ("That's it. That's the whole thing.") 6. Superficial analysis / importance puffery ("marks a pivotal moment") 7. Weasel attribution ("experts agree") 8. Synonym cycling 9. Fake-profound endings ("The future isn't coming. It's already here.") — plus fundamentals: lead with the point, active voice, concrete over abstract.

## Usage

```
/no-ai-slop (your writing)              # edit and list what changed
/no-ai-slop is this slop? (your writing) # detect without rewriting
```

## Install

```
npx skills add petergyang/no-ai-slop --skill no-ai-slop --global --yes
```
Also available as a ChatGPT plugin.
