# ux-ui-agent-skills

A comprehensive design-system + accessibility skill collection for Claude Code (and other agent harnesses), focused on generating production-ready UI/UX work artifacts: design tokens (DTCG), component libraries, WCAG compliance checks, and design-to-code output with objective “quality gates”.

## Why it’s useful

- Helps an agent behave more like a senior design architect: define tokens, components, and interaction patterns with consistency.
- Strong emphasis on accessibility (WCAG 2.2 AA→AAA) and verification via objective gates.
- Practical for shipping UI systems (not just “prompt design”).

## What’s included (high level)

- Design tokens (DTCG) generation and maintenance
- Component library scaffolding (multi-framework)
- Accessibility checks and remediation guidance (WCAG)
- Design-system evaluation gates / acceptance criteria
