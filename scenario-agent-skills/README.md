# Scenario Agent Skills

Scenario's production Agent Skills collection for generating and managing images, video, audio, and 3D assets from AI agents. It includes core Scenario MCP workflows plus specialized skills for image generation and editing, brand consistency, storyboards, game assets, Blender/Maya/ZBrush/Unreal/Unity workflows, video production, audio, model comparison, quality gates, and cost-aware execution.

## Why it qualifies

- Published and maintained by Scenario Labs.
- MIT-licensed with CI, release automation, OpenSSF Scorecard, and documented MCP/API surfaces.
- More than 4,000 stars and active maintenance, with procedural `SKILL.md` files and tests for shipped scripts.

## Install

Install the collection or selected skills with the Skills CLI:

```bash
npx skills add scenario-labs/skills
```

The repository also documents Scenario MCP setup, role- and goal-based installation groups, and specialist skill families for creative and game-production workflows.
