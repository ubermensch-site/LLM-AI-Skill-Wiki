# Product Engineer Skills

A portable suite of product and UX engineering skills for improving how people get through a real product. It covers research planning, feature briefs, happy- and unhappy-path audits, usability testing, adoption, analytics instrumentation, A/B testing, launch review, accessibility, design-system adoption, and PR-level UX review.

## Why it qualifies

- Maintained by Trystan Sarrade with a focused, clearly documented purpose.
- Ships as a real multi-agent skill package with Claude Code and Codex manifests, plus support for the open-source Skills CLI.
- Recent releases added research, usability-test, and launch-review workflows and bumped the plugin version.
- CI checks frontmatter portability, bundled-script tests, plugin validation, and Codex skill discovery.

## Key features

- Evidence-first product research and feature-brief workflows.
- Click and field budgets, KLM estimates, flow tests, and unhappy-state matrices.
- Adoption funnels, analytics instrumentation, experiment design/readouts, and post-launch review.
- Design-system extraction/adoption, WCAG 2.2 AA review, and UX review for pull requests.
- Shared feature folders so research, implementation, testing, and launch evidence build on one another.

## Install

Claude Code:

```text
/plugin marketplace add Trystan-SA/product-engineer-skills
/plugin install product-engineer@product-engineer-skills
```

Other agents with the Skills CLI:

```bash
npx skills add Trystan-SA/product-engineer-skills
```

See the upstream README for the Codex install path and version requirements.
