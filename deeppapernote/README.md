# DeepPaperNote

DeepPaperNote is an agent skill for deeply reading one paper and turning it into an illustrated, linked Obsidian note. It supports Claude Code, Codex, and other compatible agents, with companion skills for research memory, paper-library organization, and glossary creation.

Its workflow extracts figures, tables, formulas, methods, limitations, and evidence from the full paper; adapts the note structure to ten paper types; links related work; and runs quality checks before saving. It refuses to fabricate a note when the full text is unavailable.

## Why it is trustworthy

- MIT-licensed and backed by documented tests over 34 real papers, with explicit quality and evidence boundaries.
- Provides an actual plugin/skills implementation, PyMuPDF-based tooling, regression workflows, and lint/test instructions.
- Clearly distinguishes reported results from missing information and preserves existing personal notes when regenerating output.
