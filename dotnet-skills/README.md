# .NET Agent Skills

Official, curated Agent Skills and host-specific agents from the .NET team for building, diagnosing, testing, modernizing, and upgrading .NET applications.

## What it includes

- Portable skills for core .NET development, ASP.NET Core, Blazor, WinForms, .NET MAUI, data access, Entity Framework, testing, NuGet, MSBuild, diagnostics, upgrades, templates, and .NET AI/ML workflows.
- Plugin packaging for Copilot CLI, Claude Code, Cursor, VS Code, and Codex CLI.
- Reusable GitHub Agentic Workflows.
- A public Skill Value dashboard reporting token use, elapsed time, activation, and pass-rate metrics.
- Tests, contribution guidance, security policy, and an MIT license.

## Why it is trustworthy

This is the official `dotnet` organization repository maintained by the .NET team. It has substantial community adoption, active maintenance, documented installation paths, an evaluation dashboard, automated tests, and clear governance and security documentation.

## Install

Add the marketplace in Copilot CLI or Claude Code:

```text
/plugin marketplace add dotnet/skills
```

Then install a plugin:

```text
/plugin install <plugin>@dotnet-agent-skills
```

Codex CLI users can register the native marketplace:

```bash
codex plugin marketplace add dotnet/skills
```
