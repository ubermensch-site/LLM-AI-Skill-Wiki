# Research Toolkit

Research Toolkit is an evidence-first Agent Skill for industry, product, company, and technical research. It turns questions or existing material into reports with traceable sources, explicit judgments, revision records, author checks, and optional MCP workflow tools.

## Why it qualifies

- MIT-licensed repository with CI framework checks, structured documentation, tests/evaluations, and reproducible case studies.
- Offers Lite and Full workflows with clear completion criteria and transparent evidence limits.
- Maintains source and review records so report revisions can be audited rather than treated as unverified model output.
