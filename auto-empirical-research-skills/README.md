# Auto-Empirical-Research-Skills

A large, research-focused Agent Skills collection from the Stanford REAP / StatsPAI team. It packages reproducible workflows for empirical research—from question refinement and literature review through data acquisition, causal inference, estimation, robustness checks, publication-quality tables, writing, peer review, and AI-writing audits.

## Why it qualifies

- **Strong provenance:** maintained by the Stanford REAP × StatsPAI team.
- **Substantive scope:** the upstream catalog documents 78 collections and more than 1,100 individual skills rather than a thin prompt dump.
- **Quality controls:** the repository includes catalog validation, evaluation and benchmark tooling, an OpenSSF Scorecard badge, and a published security-scan report.
- **Cross-agent installation:** supports Claude Code, Codex, and other Agent Skills-compatible hosts through documented plugin and directory installation paths.
