# dzhng/skills

A composable collection of agent skills for building software factories: map unknowns, write and implement specs, run autonomous research, review decisions, and verify visual work. It supports Claude Code, Codex, Cursor, and other skill-compatible harnesses.

## Why it qualifies

- 1,400+ GitHub stars and active maintenance.
- Substantive, clearly documented skills rather than a prompt-only collection.
- Includes install tooling, a broad engineering workflow, tests/review skills, and a permissive MIT license.

## Key capabilities

- Explore unknowns and turn discoveries into independently verifiable specs.
- Implement, review, test, refactor, and close out feature work.
- Run bounded research experiments and visual screenshot reviews.
- Author and evaluate new skills.

## Install

```bash
npx skills add dzhng/skills
```
