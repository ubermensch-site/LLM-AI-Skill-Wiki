# onetake

A production-grade **Agent Skill** for generating motion-design launch films and feature demos that feel like a *single continuous take* (no “slide deck” cuts). It focuses on *continuity*: every beat visibly transforms into the next, with deterministic rendering, motion blur, and an automated “oracle” that verifies carry-over between scenes.

## What it does

- Creates short motion films (launch videos, teasers, feature demos) where each beat **grows out of** the previous beat.
- Rebuilds product UI in HTML from screenshots so the camera can fly in/out at any zoom (no screen recording).
- Includes scripts to render with motion blur, score/verify continuity, and iterate on rejected drafts.

## Why it’s trusted

- Substantive implementation (not just prompt text): includes a motion library, rendering pipeline, verification scripts, and multiple shipped example films.
- Clear documentation of methodology, constraints, and acceptance criteria.
