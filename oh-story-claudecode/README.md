# ZenStory Oh Story

A 14-skill writing suite for Claude Code, Codex, OpenCode, OpenClaw, and other compatible agents. It supports trend scanning, bestseller analysis, long- and short-form fiction, continuity tracking, AI-style cleanup, review, and cover workflows.

## Why it qualifies

- More than 8,000 GitHub stars and 1,000 forks with active releases.
- Maintained by ZenStory AI with substantial examples, docs, hooks, and local validation tooling.
- Uses file-backed project memory and explicit checks for continuity, chapter state, and AI-writing patterns; MIT licensed.

## Key capabilities

- Scan markets and analyze reference novels before writing.
- Maintain outlines, character state, plot threads, and reader-known facts on disk.
- Gate chapter writing on outlines and tracking state.
- Review prose and remove deterministic AI-writing patterns without changing story facts.

## Install

```bash
npx skills add zenstory-ai/oh-story-claudecode -y -g
```
