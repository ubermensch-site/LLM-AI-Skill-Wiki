# Forge (initializ/forge)

Forge is an **open-source, security-focused runtime** for building and deploying agents that follow the **Anthropic Agent Skills (SKILL.md) standard**.

It focuses on production concerns that most “prompt-only” skill collections ignore:
- Secure-by-default execution with **egress controls / allowlists**
- **Encrypted secrets** and auditable logs
- Portability (local, Docker, Kubernetes, on-prem, and air-gapped)
- Tooling for compiling `SKILL.md` into a runnable agent spec

## Why this is trusted

- Real product + real engineering surface (runtime, CLI, docs, security model)
- Clear alignment with the published Agent Skills standard
- Active maintenance and substantive documentation
