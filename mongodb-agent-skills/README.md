# MongoDB Agent Skills

Official MongoDB Agent Skills for Claude, Cursor, Codex, GitHub Copilot, Grok, and other compatible agent runtimes. The collection covers Atlas and self-managed MongoDB workflows, including query writing, schema design, query optimization, Atlas Search, Vector Search, deployment guidance, and connection setup.

## Why it qualifies

- Published and maintained by MongoDB.
- Apache-2.0 licensed with documented plugin and direct-skill installation paths.
- Includes CI validation, testing/evaluation assets, security-minded credential handling, and active maintenance.

## Install

Install the full collection with the Skills CLI:

```bash
npx skills add mongodb/agent-skills
```

The repository also provides official `mongodb-atlas` and `mongodb` plugins for supported agent marketplaces. For the Atlas MCP connection, follow the [MongoDB Agent Skills documentation](https://www.mongodb.com/docs/agent-skills/).
