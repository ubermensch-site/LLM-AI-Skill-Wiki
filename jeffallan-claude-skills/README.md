# jeffallan-claude-skills

A production-oriented Claude Code plugin with 71 specialized skills and 13 workflow commands for full-stack engineering. It spans languages, frameworks, backend and frontend work, infrastructure, APIs, testing, DevOps, security, data/ML, and platform concerns, with a spec-driven workflow from discovery and ticket execution through review and completion.

## Why it qualifies

- Maintained by Jeff Allan, a principal full-stack and security engineering consultant.
- Strong community traction, MIT licensing, published documentation, releases, and CI validation.
- Substantive implementation with plugin metadata, reference files, agents, workflow tooling, tracker adapters, tests, and upgrade guidance rather than a prompt-only collection.

## Highlights

- 71 skills organized across 12 technical categories.
- 13 workflow commands cover discovery, specs, ticket execution, review, completion, intake, and current-state checks.
- Supports GitHub Issues, GitHub Projects, Jira, Linear, and text-ticket workflows.
- Includes specialized agents for code reading, documentation, test writing, security probing, architecture, review, verification, and assumption checking.

## Install

Claude Code marketplace:

```text
/plugin marketplace add jeffallan/claude-skills
/plugin install fullstack-dev-skills@fullstack-dev-skills
```

See the source README and documentation for the complete skill catalog, workflow setup, tracker configuration, and other supported installation paths.
