# Awesome Claude Code

"A hand-picked collection of the finest resources for the most awesome of agents, Claude Code." Covers skills, subagents, status lines, developer tooling, and plugins.

## What it does

- **From Anthropic** — links to official Claude Code docs, the official plugin directory, and Anthropic engineering blog posts on agent design
- Dedicated sections for Skills, Agent Orchestration, Memory & Context Persistence, Observability & Monitoring, Security, and Linting
- A "recently added" ticker and ongoing curation (legacy entries preserved in `README_ALTERNATIVES/`)
- Strong emphasis on code quality, security, and originality when selecting entries — explicitly avoids low-effort AI-slop submissions

## Why it's trusted

One of the most-referenced Claude Code "awesome list" repositories in the community, actively maintained with strict curation standards, and frequently cited by other trusted lists (including several in this wiki).
