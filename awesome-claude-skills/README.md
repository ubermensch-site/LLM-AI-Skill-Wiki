# Awesome Claude Skills (by Composio)

A comprehensive, curated list of 1000+ production-ready Claude Skills and plugins for Claude.ai, Claude Code, and other coding agents (Codex, Cursor, Gemini CLI, Antigravity).

## What it does

Organizes real, community- and vendor-contributed skills into categories:

- Document Processing (docx, pdf, pptx, xlsx, legal document packs)
- Development & Code Tools (MCP builder, webapp testing, CI/CD, architecture)
- Data & Analysis (CSV summarizers, deep research, Postgres querying)
- Business & Marketing, Communication & Writing, Creative & Media
- Productivity & Organization, Collaboration & Project Management
- Security & Systems, and App Automation via Composio's MCP Gateway (1000+ app integrations)

Each entry links directly to the skill's source repo and credits its author.
