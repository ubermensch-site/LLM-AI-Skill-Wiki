# Awesome Design Skills

A curated registry of 67 design-system skill files for Claude Code, Cursor, Codex, and other agentic tools. Each entry pairs an agent-facing `SKILL.md` with a human-readable `DESIGN.md`.

## What it includes

- Brand, typography, color, spacing, and component-system guidance
- Accessibility constraints and WCAG 2.2 AA-oriented rules
- Explicit do/don't patterns and quality gates for generated UI
- A broad set of visual directions, from minimal and corporate to brutalist, retro, neon, and glassmorphic
- A CLI-backed registry for browsing and pulling individual skills

## Why it is trustworthy

This is a structured, MIT-licensed registry with clear contribution requirements, stable skill metadata, companion design documentation, and a practical install workflow. Its strong community adoption and maintained TypeUI tooling make it more than an unstructured list of prompts.

## Install

Browse the registry or pull a design skill into a project:

```bash
npx typeui.sh list
npx typeui.sh pull glassmorphism
```

See the upstream README for provider selection, dry runs, custom-skill generation, and the complete catalog.
