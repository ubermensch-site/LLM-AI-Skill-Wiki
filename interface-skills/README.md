# interfaces.dev Skills

A focused collection of agent skills for building and reviewing high-quality interfaces. The pack covers accessibility, layout, typography, color, product writing, UI polish, component states, design-image implementation, and interface reviews.

## Why it qualifies

- More than 11,000 GitHub stars and active usage through the skills ecosystem.
- Authored and documented by Jakub Krehel through his design-engineering site and magazine.
- Skills include concrete WCAG, layout, typography, color, and review guidance rather than generic design prompts.

## Key capabilities

- Audit and improve accessibility, responsive layout, typography, color, and interface copy.
- Review branches and pull requests for visual regressions.
- Render component states and stress-test interfaces on temporary pages.
- Build UI from Figma files or design images using existing project tokens.

## Install

```bash
npx skills add jakubkrehel/skills
```
