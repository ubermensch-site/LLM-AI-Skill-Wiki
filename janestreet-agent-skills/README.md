# Jane Street Agent Skills

A small public collection of Agent Skills shared by Jane Street. The repository currently publishes a Socratic tutoring skill that turns an AI agent into a structured personal tutor with diagnostics, skill maps, one-question-at-a-time teaching, spaced review, and a final assessment.

## Why it is trustworthy

- Published by Jane Street, a well-known quantitative trading and technology firm.
- The source README says the skills are exported from Jane Street's internal repository and used day to day.
- Uses the common `SKILL.md` format and documents installation for coding agents and plain chatbots.

## Source

- Repository: [janestreet/agent_skills](https://github.com/janestreet/agent_skills)
- Install or copy the `socratic-tutor` skill from the source repository, then ask the agent to teach a topic.
