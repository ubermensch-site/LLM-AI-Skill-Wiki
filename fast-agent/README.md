# fast-agent

A CLI-first framework for building, running, and evaluating agent applications — with first-class support for **Agent Skills (`SKILL.md`)** and **MCP**.

## What it does

- Runs interactive or scripted agent sessions with shell support
- Connects to MCP servers (stdio, SSE, HTTP/streamable HTTP + OAuth)
- Manages and installs skill packs, and includes a registry of skills for common agent workflows
- Supports workflow patterns like chaining, parallel fan-out/fan-in, router, orchestrator, and evaluator-optimizer loops

## Why it’s trusted / worth including

- Substantive implementation (not prompt-dumpware): CLI, workflow runtime, docs, and CI
- Strong community traction and active maintenance
- Explicitly positions **Agent Skills (`SKILL.md`)** as a core feature
