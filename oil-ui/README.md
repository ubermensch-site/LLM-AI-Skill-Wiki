# Oil UI

Oil UI is an interface-design skill for AI agents that helps create and refine websites, apps, dashboards, and components. It researches distinctive peer products, turns vague goals such as “premium” into concrete typography, spacing, color, and composition decisions, and checks the real result at desktop and mobile sizes with screenshot-based review.

## Why it qualifies

- 2,500+ GitHub stars and active maintenance as of this review.
- MIT licensed, with substantial documentation and a reproducible installation path.
- A concrete `SKILL.md` workflow rather than a thin prompt collection, including side-by-side design comparison and visual quality checks.

## Key capabilities

- Product and competitor-informed design direction.
- Multiple genuinely different visual directions with a built-in comparison page.
- Screenshot recreation, responsive checks, memorable interaction moments, and subtraction-focused polish.
- Compatible with the Agent Skills ecosystem and installable with `npx skills add`.

## Install

```bash
npx skills add oil-oil/oil-ui
```
